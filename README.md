# Учёт железнодорожных билетов

Консольная программа на C++17 для работы со списком железнодорожных билетов. Данные хранятся в CSV-файле.

Можно загрузить билеты из файла, добавить или изменить запись, удалить билет, отсортировать список, найти билеты по пункту маршрута и посмотреть минимальную, максимальную и среднюю цену. Перед изменением данных программа просит подтверждение. Ввод можно отменить, набрав `0`.

## Сборка

Понадобятся CMake 3.16+, компилятор C++17 и Ninja.

```sh
cmake -S . -B build -G Ninja
cmake --build build
ctest --test-dir build --output-on-failure
```

Запускайте `TicketsDatabase` из папки `build` (в Windows - `build/TicketsDatabase.exe`). После запуска список пуст. Чтобы загрузить образец, выберите пункт **1** и укажите `sample.csv`. При сохранении имя по умолчанию - `tickets.csv`; если расширение не указано, оно добавляется автоматически.

## Формат CSV

Файл содержит по одному билету на строку без заголовка:

```csv
235,3450,Москва,Казань,купе
```

Поля по порядку: номер поезда, цена в рублях, пункт отправления, пункт прибытия, тип места. Кодировка - UTF-8; при сохранении добавляется BOM для корректного открытия файла в Windows. Для текстовых полей с запятой или кавычкой используется стандартное CSV-экранирование.

Неверная строка прерывает загрузку, при этом текущий список билетов остаётся без изменений. Поиск по латинским буквам не учитывает регистр; кириллический ввод сравнивается с учётом регистра.
